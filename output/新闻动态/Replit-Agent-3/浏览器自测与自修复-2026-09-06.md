# Replit Agent 3：会自己打开浏览器测你的 App，再试着修

**一句话**：Replit 2025-09-10 发布 Agent 3，主打 **更高自治**——周期性在浏览器里测应用、自动修问题；数字是厂商自述，第三方长评还少。

日期：2026-09-06

---

## 官方说了啥

[发布文](https://replit.com/blog/introducing-agent-3-our-most-autonomous-agent-yet) 要点：

- 相对 Agent V2，自称自治性提升约 **10 倍**（没给公开 benchmark 名）  
- 能 **定期在浏览器测 App**，用自研测试系统修 bug  
- 自称比 Computer Use 类方案 **更快、更便宜**（同样缺对照细节）  
- 还能 **生成别的 agent / 自动化** 串工作流  

## 怎么理解

本质是把 **「写完 → 跑起来 → 看图 → 再改」** 往产品里塞，减少你手动点一遍 UI。  
和开源 harness 不同：实现封闭在 Replit 里，外面看不清规格。
