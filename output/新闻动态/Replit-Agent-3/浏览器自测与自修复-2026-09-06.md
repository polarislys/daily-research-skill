# Replit Agent 3：把 browser 自测写进产品，数字先当厂商自述

2025-09-10 [Replit 发了 Agent 3](https://replit.com/blog/introducing-agent-3-our-most-autonomous-agent-yet)，主打更高自治：周期性在 **browser** 里测 App，用自研测试系统自修复，还能生成别的 agent / automation 串工作流。

本质是把 **eval loop** 塞进产品——写完 → 跑起来 → 看图 → 再改。harness 封闭在 Replit 栈里，外面看不清 spec。

博客里的「相对 V2 10x autonomous」「比 Computer Use 3x 快、10x 便宜」**没有** 公开 benchmark 名和对照细节。本检索窗也 **没有** 像 Copilot coding agent GA 那样热的 HN 长帖或独立长评测——下手结论宜保守。
