# Skill Imitation Trap：skill-RAG 检索多了，有时反而更坚持用错 tool

美团 + 中科院自动化所预印本 [When Not to Imitate](https://arxiv.org/abs/2608.22339) 提了一个反直觉现象：**Skill Imitation Trap**。

很多人默认：把成功 trajectory 蒸馏进 **Skill / skill memory**，检索进来应该单调变好。他们测出来——任务和旧成功案例很像、其实该换 tool 时，**检索到的 procedure skill 越多，模型对 wrong tool 越自信**（相对无 memory 基线，wrong-tool margin 大约 +47%）。

## 对你意味着什么

**skill-RAG** 不是堆越多越好。要分清什么时候该模仿旧 procedure、什么时候该打破。论文里的 **BASM** 是缓解方向之一，细节见原文。

这和 **skill 自进化** 是两条线：自进化改 Skill 文件内容；这篇讲的是 **检索阶段** 的失效模式。
