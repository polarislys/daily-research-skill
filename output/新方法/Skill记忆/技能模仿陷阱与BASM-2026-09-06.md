# Skill Imitation Trap：检索 procedure skill 多了，反而更坚持用错 tool

**一句话**：论文 [When Not to Imitate](https://arxiv.org/abs/2608.22339) 发现——该换 tool 时，**skill-RAG** 检索来的 procedure skill 越多，模型对 **wrong tool** 越自信（相对无 memory 基线，wrong-tool margin 约 +47%）。

日期：2026-09-06

---

## 背景

常见假设：把成功 trajectory 蒸馏进 **Skill / skill memory**，检索进来应该单调变好。

作者称这会在某些场景触发 **Skill Imitation Trap**：任务和旧成功案例很像、其实该换 tool 时，越模仿越错。

## 对你意味着什么

**skill-RAG** 不是堆越多越好。要分清何时该模仿旧 procedure、何时该打破。  
**BASM** 是论文提出的缓解方向（细节见原文），核心是别盲信检索 Skill。

## 和 skill 自进化

自进化改的是 Skill 文件内容；本文讲的是 **检索阶段** 的失效模式——两条线都要看。
