# MASkills：别一个 Agent 改 Skill，让多个 Agent 分工改

**一句话**：技能写在文件里（SKILL.md 等），多个 Agent 各自带技能库，用分工 + 信用分配决定 **该谁改哪份 Skill**。

日期：2026-09-06

---

## 这是个啥

[MASkills 论文](https://arxiv.org/abs/2609.02094)（EMNLP 2026 Findings）研究 **Skill 自进化**，但不用「一个大模型独自 rewrite 所有 Skill」。

每个 Agent 有自己的技能包：`SKILL.md`、配置、脚本等。优化改的是 **这些文件**，不是模型权重。

## 解决什么痛

- 只记经验（Reflexion 一类）：记得住，不好调用，一长就噪  
- 单 Agent 改 Skill：队友已经学会的技能，你不知道该归功给谁  

MASkills 用多 Agent + **技能层面的信用分配**，再配合精炼、合并、 pruning、回滚等操作。

## 实验与代码

论文报在 HotpotQA、LoCoMo、GAIA 等任务上有提升。
