# MASkills：多 Agent 在 skill 空间做 credit assignment，而不是单模型 rewrite

**一句话**：**MASkills** 让每个 Agent 带 `{SKILL.md, skill.yaml, 脚本}` 技能库，优化改 **skill 文件** 而非权重；用多 Agent **skill-level credit assignment** 决定谁该改哪份 Skill。

日期：2026-09-06

---

## 问题

- **Reflexion** 类经验记忆：记得住，不好调用，一长就噪  
- 单 Agent **skill 自进化**：队友已学会的技能，归责不清  

## MASkills 做法

多 Agent 各自维护 skill 库；在语言空间做类似策略梯度的流水线：**skill-conditioned credit assignment**、分层汇总、动量平滑，再 refinement / induction / consolidation / pruning，带 hold-out 验证和回滚。

实验报在 HotpotQA、LoCoMo、GAIA 有提升。
