# MASkills：多 Agent 在 skill 空间做 credit assignment，而不是单模型 rewrite

[MASkills](https://arxiv.org/abs/2609.02094)（EMNLP 2026 Findings）研究 **skill 自进化**，但不让一个大模型独自 rewrite 所有 Skill。

每个 Agent 带自己的技能库：`SKILL.md`、`skill.yaml`、脚本等；优化改的是 **这些文件**，不是权重。痛点是：Reflexion 类经验记得住但不好调用；单 Agent 改 Skill 时，队友已经学会的技能，归责不清。

MASkills 用多 Agent + **skill-level credit assignment**（技能条件信用分配、分层汇总、动量平滑），再 refinement / induction / consolidation / pruning，带 hold-out 验证和回滚。论文报在 HotpotQA、LoCoMo、GAIA 有提升，代码在 [DaRL-GenAI/MASkills](https://github.com/DaRL-GenAI/MASkills)。
