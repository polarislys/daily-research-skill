# iStar：不用人工给每一步打分，也能练多步 Agent

**一句话**：和 TIGPO/PGPO 同族问题；iStar 用「轨迹对比」隐式长出 **每一步该奖多少**，不用额外标注，还能接到 GRPO 等常见训练算法上。

日期：2026-09-06

---

## 问题还是那句

多步 Agent 训练，**最后才知道输赢**，中间步很难分功过。  
人工逐步打分太贵，还容易被人钻空子（reward hacking）。

## iStar 怎么做（白话）

1. 和策略 **轮流训练** 一个「隐式过程奖励」模型  
2. 用 **轨迹级 DPO**（偏好：这条轨迹比那条好）推出每一步的分  
3. 把 **步级分数 + 整条轨迹分数** 合在一起更新策略  

不用多跑一轮环境，也不用人标「第 3 步对了」。
