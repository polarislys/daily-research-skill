# Claude Managed Agents：brain 先想，sandbox（hands）需要时再开

Anthropic 在推 [Managed Agents](https://www.anthropic.com/engineering/managed-agents)——托管的长时程 Agent：**harness**（loop、tool 路由、context compaction、重试）他们维护，会话可以跑很久，断线能从 event log 恢复。

文里有个好比喻：**decoupling brain from hands**。

- **brain**：模型 + 决定下一步的 harness  
- **hands**：sandbox / 容器里真正跑代码  

关键细节：hands 不是会话一开始就常驻。没立刻要隔离执行时，推理可以先启动；brain 通过 `execute` **按需** 要 sandbox。官方称这样能明显降 **TTFT**（首 token 延迟）——外部还没普遍复现，但机制上说得通：别让用户空等容器。

## 为什么托管 harness 本身有价值

自己搭 Agent 要拼进程监督、sandbox、压缩上下文、失败恢复。托管版由供应商维护，且会在新模型出来时拆掉过时设计——比如为旧模型的「context anxiety」写的强制 reset，新模型可能不需要了，旧 harness 反而拖后腿。

适合读 repo → 改代码 → 测试 → 开 PR 这种一小时级任务；一句问答用 Messages API 更划算。
