# Claude Managed Agents：brain / hands 分离，sandbox 按需开

**一句话**：Anthropic 托管长时程 Agent；推理可先启动，**sandbox** 通过 `execute` 按需 provision——官方称可明显降 **TTFT**。

日期：2026-09-06

---

## 这是个啥

[Managed Agents](https://www.anthropic.com/engineering/managed-agents) 是 Claude 平台上的托管 **harness**：长会话、断线从 event log 恢复、tool 调用可追踪。

**Decoupling brain from hands**：

- **brain**：模型 + 决定下一步的 harness  
- **hands**：sandbox / 容器里真正跑代码  

hands 不是会话开始就常驻；没立刻要隔离执行时，推理可以先跑——官方给了 p50/p95 TTFT 降幅，外部尚未普遍复现。

## 为什么值得关注

自建 Agent 要拼：进程监督、sandbox、context compaction、重试。托管版由 Anthropic 维护 harness，且会在新模型上线时拆掉过时设计（例如旧模型需要的强制 context reset，新模型可能不需要）。

## 适合什么 workload

- 适合：读 repo → 改代码 → 测试 → 开 PR，可能一小时  
- 不适合：一句问答，用 Messages API 更便宜
