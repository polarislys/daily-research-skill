# Claude Managed Agents：脑子先开工，手（沙盒）需要时再开

**一句话**：Anthropic 托管长任务 Agent；**推理可以先开始**，隔离环境按需创建，不用每个会话开头空等容器。

日期：2026-09-06

---

## 这是个啥

[Claude Managed Agents](https://www.anthropic.com/engineering/managed-agents) 是 Anthropic 平台上的 **托管 Agent 运行时**：会话可以跑很久，断线能从日志恢复，工具调用可追踪。

官方用 **「脑手分离」** 打比方：

- **脑**：模型 + 决定下一步的环  
- **手**：真正跑代码的沙盒/容器  

手不是会话一开始就必开；脑通过工具 **按需申请** 沙盒。这样首字延迟（TTFT）能明显下降——官方给了 p50/p95 降幅数据，但外部还没普遍复现。

## 为啥值得看

自己搭 Agent 往往要拼：进程监督、沙盒、压缩上下文、失败重试。托管版把这些维护交给供应商，且他们会在新模型出来时 **拆掉过时的环设计**（例如旧模型需要的强制「清空上下文」，新模型可能不需要了）。

## 适合什么任务

- 适合：读仓库 → 改代码 → 测试 → 开 PR，可能一小时的那种  
- 不太适合：一句问答就结束，用普通 API 更便宜
