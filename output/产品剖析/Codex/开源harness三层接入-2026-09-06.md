# Codex 开源 harness：按三层接进你的项目

**一句话**：模型在最内；中间是 Codex **harness**（agent loop、tool、权限）；最外是你自己的 Skill、MCP、审批规则。

日期：2026-09-06

---

## 这是个啥

OpenAI 开源了 [Codex](https://github.com/openai/codex)（Rust CLI）。它不只是 chatbot，而是一套 **harness**——包在模型外的 agent loop、tool dispatch、重试和 guardrails，把「会说话的模型」收成能开 PR 的 Agent。

## 三层

| 层 | 干什么 | 你怎么接 |
|---|---|---|
| 模型 | 推理、出 patch | 换 API / 换模型 |
| Codex harness | 读文件、跑 shell、开 PR、循环 | 用官方 CLI 或学其接口 |
| 你的层 | 规范、私有 tool、审批 | Skill、`hooks`、MCP server |

**Skill**（`SKILL.md`）：仓库里可版本管理的「怎么做 X」，Agent 按需加载，避免每次重复长 prompt。

**sandbox**：不信任代码的隔离执行；**MCP** 是连工具的协议，本身不等于 sandbox，要看执行跑在哪。

## 和 Copilot 补全差在哪

补全是一行一行建议。Codex harness 跑的是整条任务链：**读 repo → 改代码 → 跑检查 → 开 PR**，状态在 loop 里转。
