# Codex 开源夹具：你可以按三层把它接进自己的项目

**一句话**：最里面是模型；中间是 Codex 自带的执行环；最外面是你自己的工具、规则和审批。

日期：2026-09-06

---

## 这是个啥

OpenAI 把 [Codex](https://github.com/openai/codex) 开源了（Rust 写的 CLI）。它不只是「能写代码的聊天框」，而是一套 **包在模型外面的执行环**（业内常叫 harness）：能调工具、能重试、能管权限。

## 三层怎么理解

| 层 | 干什么 | 你可以怎么接 |
|---|---|---|
| 模型层 | 想下一步、生成补丁 | 换模型、换 API |
| Codex 环 | 读文件、跑命令、开 PR、循环重试 | 用官方 CLI，或学它的接口设计 |
| 你的层 | 公司规范、私有工具、审批规则 | 写 Skill 文件、hook、MCP 工具 |

**Skill 文件**（`SKILL.md` 一类）= 把「我们仓库怎么做事」写进可版本管理的文件，Agent 按需读，而不是每次聊天重复一遍。

**沙盒**：不信任的代码要在隔离环境里跑；光有 MCP 协议不等于已经隔离好了，还得看实际跑在哪。

## 和「又一个 Copilot」差在哪

Copilot 补全是一行一行帮你想。Codex 夹具是一整条任务：**读仓库 → 改代码 → 跑检查 → 开 PR**，中间状态在环里转，不是一问一答结束。
