# Codex 开源了 harness，你可以按「模型 / Codex / 你的规则」三层来接

OpenAI 把 [Codex CLI](https://github.com/openai/codex) 开源了。很多人只把它当「能写代码的终端」，但它真正值钱的是外面那圈 **harness**——agent loop、tool dispatch、重试、guardrails，把模型收成能开 PR 的 Agent。

这篇只答一件事：**想接 Codex，三层各放什么。**

## 为什么不是「又一个 Copilot」

Copilot 补全帮你一行一行想。Codex harness 跑的是整条链：读 repo → 改代码 → 跑检查 → 开 PR。状态在 loop 里转，不是问答结束就散。

## 三层

最里面是 **模型**（换 API、换模型）。中间是 **Codex harness**（读文件、跑 shell、循环重试）。最外是你自己的层：公司规范、私有 tool、审批——通常用 **Skill** 文件（`SKILL.md`）、hook、**MCP** server 来接。

有两处别混：**MCP** 是连工具的协议；**sandbox** 是代码跑在哪、隔离到哪一级。有 MCP 不等于已经 sandbox。

同一套 harness 思路，OpenAI 在 [Harness engineering](https://openai.com/index/harness-engineering/) 里又往前推了一步：少手写代码，多设计 repo 规则和 CI，让 Agent 能自己验 PR——那是同文件夹另一篇要讲的「环境」方向。
