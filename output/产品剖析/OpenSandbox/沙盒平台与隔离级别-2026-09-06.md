# OpenSandbox：Agent 跑不可信代码时，sandbox 要分级别

**一句话**：不同任务风险不同，**sandbox** 隔离不能一刀切；OpenSandbox 做可配置隔离平台。

日期：2026-09-06

---

## 这是个啥

[OpenSandbox](https://github.com/alibaba/OpenSandbox)（阿里开源）给 Agent 提供跑不可信代码的环境。**sandbox** 限制文件、网络、系统调用；级别越高越严，开销越大。

## 和 harness 怎么叠

**harness** 管 loop 和 tool 调用；**sandbox** 管 tool 在哪执行。OpenSandbox 常作外层执行环境。  
和 Temporal **outer harness**（任务挂起续跑）是不同维度，可以一起用。

**MCP** 连工具 ≠ 已 sandbox，要看 backend。
