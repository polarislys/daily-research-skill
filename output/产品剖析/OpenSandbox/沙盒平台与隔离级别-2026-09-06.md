# OpenSandbox：Agent 跑代码时，隔离要分等级

**一句话**：不同任务危险程度不同，沙盒不能「一刀切」；OpenSandbox 做的是可配置隔离的平台化方案。

日期：2026-09-06

---

## 这是个啥

[OpenSandbox](https://github.com/alibaba/OpenSandbox)（阿里开源）给 Agent 提供 **跑不可信代码的地方**。  
**沙盒** = 限制它能访问什么（文件、网络、系统调用）；级别越高越严，开销也越大。

## 为啥 Agent 特别需要

Agent 会自己写 shell、装包、拉网络。没有沙盒，一次幻觉命令可能删库。  
注意：**MCP 连上工具 ≠ 已经沙盒**，还得看工具背后执行在哪。

## 和 Harness 怎么配合

Harness 负责「循环 + 调工具」；沙盒负责「工具跑在哪」。OpenSandbox 常作为 **外层执行环境**，和 Temporal 那种「任务能挂起续跑」是不同维度，可以叠。
