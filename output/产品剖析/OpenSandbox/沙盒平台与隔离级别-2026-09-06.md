# OpenSandbox：Agent 跑不可信代码时，sandbox 级别不能一刀切

Agent 会自己写 shell、拉网络。没有 **sandbox**，一次幻觉命令可能删库。[OpenSandbox](https://github.com/alibaba/OpenSandbox)（阿里开源）做的是：**不同风险用不同隔离级别**，平台化配置，而不是「要么全信要么全禁」。

## harness 和 sandbox 各管什么

**harness** 管 loop 和 tool 调用；**sandbox** 管 tool 在哪执行。OpenSandbox 常作外层执行环境。

这和 Temporal 的 **outer harness**（任务挂起、续跑）是不同维度——一个管隔离，一个管跨天状态，可以叠。

再次提醒：**MCP** 连上工具 ≠ 已经 sandbox。
