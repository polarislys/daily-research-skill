# Temporal Agent Harness：长任务别靠进程硬扛，用「外层夹具」挂起再续

**一句话**：Agent 任务可能跑几小时；Temporal 这类工作流引擎负责 **状态持久化 + 失败重试**，模型进程挂了也能从断点接着干。

日期：2026-09-06

---

## 这是个啥

**内层夹具**：模型周围那一圈 tool loop（读文件、跑命令）。  
**外层夹具**：管「这一步完了没有、要不要重试、人要不要批、明天接着跑」。

[Temporal 的 Agent Harness](https://temporal.io/blog/temporal-agent-harness-durable-agent-infrastructure) 做的是外层：把 Agent 步骤当成 **可持久的工作流**，不是单进程一口气跑完。

## 解决什么痛

- 任务太长，机器重启/网络断了就全丢  
- 需要等人审批，进程不能一直占着  
- 某步失败只想重试那一步，不想从头来

## 白话类比

内层像「工人当场干活」；外层像「项目管理系统记进度」。工人换了一批，进度表还在。
