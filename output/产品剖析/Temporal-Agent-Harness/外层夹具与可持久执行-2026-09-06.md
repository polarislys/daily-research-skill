# Temporal 解决的是 outer harness：任务能挂起，明天接着跑

Agent 任务跑几小时很常见。单进程硬扛，重启就丢进度。[Temporal 的 Agent Harness](https://temporal.io/blog/temporal-agent-harness-durable-agent-infrastructure) 把步骤当成 **可持久 workflow**：某步失败只重试那步，等人审批完明天接着干，不用从头来。

## inner 和 outer 别混

**inner harness** 是模型周围的 tool loop——读文件、跑命令。  
**outer harness** 管跨进程、跨天的调度与状态；Temporal 做的是这一层。

白话一点：inner 是当场干活的工人；outer 是记进度的项目表——工人换了，表还在。

这和「模型更强了能不能一次跑完」是两条线：inner 可以越来越能扛，长业务仍可能需要 outer 记状态、等人、合规审计。
