# Temporal Agent Harness：长任务用 outer harness 挂起续跑

**一句话**：**inner harness** 管 tool loop；**outer harness** 管状态持久化、重试、等人审批——Temporal 做的是后者。

日期：2026-09-06

---

## 这是个啥

Agent 任务可能跑几小时。单进程硬扛：重启就丢进度。

[Temporal Agent Harness](https://temporal.io/blog/temporal-agent-harness-durable-agent-infrastructure) 把步骤当成 **可持久 workflow**：失败重试某步、人审批后明天接着跑，不从头来。

## inner / outer

- **inner harness**：模型周围的 agent loop（读文件、跑命令）。  
- **outer harness**：跨进程/跨天的调度与状态（Temporal 这一类）。

白话类比：inner 是当场干活；outer 是项目管理系统记进度——工人换了，进度表还在。
