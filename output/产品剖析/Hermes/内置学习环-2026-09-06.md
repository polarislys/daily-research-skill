# Hermes：学习环写进 agent runtime，不是外挂脚本

**一句话**：hermes-agent 把「试 → 看结果 → 调整」放进 **agent runtime**；和改 Skill 文件的 skill 自进化不是同一条路。

日期：2026-09-06

---

## 这是个啥

[Nous hermes-agent](https://github.com/NousResearch/hermes-agent) 是开源 Agent 运行时，内置 **learning loop**：任务过程中根据反馈调整行为，而不是只靠事后改 prompt。

## 和 skill 自进化怎么分

| | skill 自进化（如 Warp） | Hermes learning loop |
|---|---|---|
| 改什么 | 仓库里 Skill 文件 | 运行时策略/适应（见仓库定义） |
| 要不要 PR | 要 | 不一定走文件 PR |
| harness 角色 | 编排何时改 Skill | 管 loop 怎么转 |

读任何「会学习」的产品，先问：**改的是文件还是当次 runtime 状态？**
