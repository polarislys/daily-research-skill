# Hermes 把学习环写进 agent runtime，不是外挂一个脚本

[Nous 的 hermes-agent](https://github.com/NousResearch/hermes-agent) 开源的是一整套 **agent runtime**。它的卖点之一是 **learning loop**：任务跑着就能根据反馈调整，而不是每次结束再让人改 prompt。

读「会学习的 Agent」时，先问一句：**改的是文件，还是 runtime 里的行为？**

## 和 skill 自进化不是一条路

Warp 那条路是改仓库里的 **Skill** 文件，走 PR、人审。Hermes 更偏运行时里的适应（训练/策略语义，见仓库定义）。都叫「学习」，机制不一样。

**harness** 在 Hermes 里管的是 loop 怎么转；若你要的是「规程写进 git、可 diff」，看 Skill 自进化；若你要的是「runtime 内纠偏」，Hermes 是对照样本。
